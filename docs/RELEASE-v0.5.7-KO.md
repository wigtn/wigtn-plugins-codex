# v0.5.7: Visual Craft와 읽기 전용 자동 검사

UI·문서·보고서·발표자료를 제작하거나 실질적으로 다듬을 때 구성, 정보 밀도,
문구, 줄바꿈과 과도한 장식을 검토하는 `visual-craft`를 추가했습니다.
Core 스킬은 9개에서 10개로 늘며, 기존 스킬과 호출 정책은 유지합니다.

## 적용 방식

공통 기준을 읽고 요청한 산출물에 맞는 UI 또는 문서 참조를 선택합니다.
기존 브랜드·인용문·수치·요구사항을 보존하며, 파일 생성과 렌더링은 해당
형식의 전문 워크플로를 따릅니다. 일반 대화·백엔드·오타 수정에는 개입하지 않습니다.
`$wigtn-plugins-with-codex:visual-craft`로 명시하거나 자연어 제작 요청에서
Codex가 선택하도록 사용할 수 있습니다.

## 자동 검사

- HTML·Markdown 검사: 중복 ID, 문서 언어, 내부 링크 대상, 입력 라벨,
  제목 단계, 강제 줄바꿈과 반복 기호를 검사합니다. Python 표준 라이브러리만
  사용하며 파일 수정·스크립트 실행·외부 요청을 하지 않습니다.
- 브라우저 검사: 허용된 브라우저의 현재 화면에서 페이지 넘침, 잘린 글자,
  작은 글자와 작은 클릭 영역을 측정합니다. 별도 브라우저 실행기나 훅은 추가하지 않습니다.
- 확실한 소스 오류와 문맥 검토 항목을 구분합니다. 의도적인 말줄임,
  동적 라우트, 인용문과 브랜드를 경고 제거 목적으로 바꾸지 않습니다.

## 검증 범위

릴리스 검증은 `bash scripts/validate.sh`로 실행합니다. 자동 검사 회귀 테스트
17개와 그중 Node 기반 테스트의 합성 DOM 측정 조건 10개를 포함합니다.
CI에 Node를 명시해 측정 조건 테스트를 실행하도록 했습니다.

로컬 HTML 시안 3개는 소스 검사상 검출 항목이 없었습니다. 실제 브라우저
통합 검증과 디자인 품질 비교는 아직 완료하지 않았습니다. 자동 선택 설정과
키워드 예시는 실제 호출 성공률을 입증하지 않으며, 모델 성능·속도·토큰 개선을
주장하지 않습니다. 자동 검사는 시각 검수나 전체 접근성 검사를 대체하지 않습니다.

과거 full8/full9 실험의 스킬 구성은 유지합니다. Knowledge Wiki는 공동 버전
정책에 따라 manifest 버전만 변경합니다.

임시 개인용 `visual-craft`를 설치했다면 배포본과 비교해 로컬 수정 여부를
확인한 뒤 백업하고 중복 등록을 정리하세요. 업데이트 후 새 Codex 작업을 시작하세요.
