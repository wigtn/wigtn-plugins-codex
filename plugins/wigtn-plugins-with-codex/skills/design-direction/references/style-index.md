# Style Reference Index

| Direction | Reference | Best fit |
|---|---|---|
| Editorial | [reference](styles/editorial.md) | narrative, publishing, content-led products |
| Swiss Minimal | [reference](styles/swiss-minimal.md) | rigorous grids and neutral hierarchy |
| Minimal Corporate | [reference](styles/minimal-corporate.md) | restrained B2B and operations tools |
| Bento Grid | [reference](styles/bento-grid.md) | modular dashboards and feature overviews |
| Dark Mode First | [reference](styles/dark-mode-first.md) | technical, media, or low-light products |
| Neobrutalism | [reference](styles/neobrutalism.md) | bold consumer or experimental interfaces |
| Liquid Glass | [reference](styles/liquid-glass.md) | depth-rich platform surfaces used sparingly |
| Terminal/Hacker | [reference](styles/terminal-hacker.md) | developer and security tools |
| Retro Pixel | [reference](styles/retro-pixel.md) | playful, game-like, nostalgic products |
| WIGTN Brand | [reference](../../wigtn-presentation/references/brand.md) | explicit WIGTN identity |

`Brutalist` and generic `Minimalism` are intentionally excluded: Neobrutalism and the two specific minimal directions provide clearer implementation contracts with less overlap.
